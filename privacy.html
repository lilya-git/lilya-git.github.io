Kebijakan privasi

Kebijakan ini menjelaskan pengelolaan data dalam Regression Village (com.entranestudio.regressionvillage), game dari Entrane Studio, dan website developer ini.

Data permainan di perangkat

Game tidak mewajibkan pembuatan akun. Nama tokoh yang kamu masukkan, pilihan cerita, pengaturan, dan berkas simpanan disimpan di perangkat. Fitur game saat ini tidak mengunggah simpanan tersebut ke server Entrane Studio.

Unduhan dan pembaruan

Game mengambil data awal dan pembaruan melalui Cloudflare. Saat terhubung, layanan infrastruktur dapat memproses alamat IP, waktu permintaan, informasi teknis yang menyertai permintaan, serta file yang diminta untuk mengirim konten, menjaga keamanan, dan mengoperasikan layanan. Koneksi unduhan memakai HTTPS. Data yang sudah diunduh dapat digunakan offline.

Kebijakan privasi Cloudflare

Iklan dan persetujuan

Game menggunakan Google AdMob untuk iklan di jeda pergantian hari. SDK iklan dapat mengumpulkan dan membagikan alamat IP (termasuk perkiraan lokasi umum), identitas iklan/perangkat atau aplikasi, interaksi iklan dan aplikasi, serta informasi diagnostik. Data ini digunakan untuk penayangan dan pengukuran iklan, analitik layanan iklan, keamanan, dan pencegahan penipuan.

Pilihan persetujuan disajikan melalui Google User Messaging Platform ketika diperlukan. Jika tersedia, gunakan opsi privasi iklan dalam game untuk meninjau pilihanmu. Kamu juga dapat mengatur atau menghapus ID iklan melalui pengaturan privasi Android. Game melewati iklan yang tidak tersedia; bermain offline tidak memerlukan penayangan iklan.

Lihat kebijakan privasi Google dan cara Google menggunakan data aplikasi mitra. Versi ini belum mengintegrasikan SDK Yandex, AppLovin, Unity Ads, atau Pangle secara terpisah.

Website dan dukungan

Website ini tidak menambahkan alat analitik atau iklan. Website dihosting di GitHub Pages. GitHub dapat memproses informasi teknis permintaan, termasuk alamat IP, untuk mengirim halaman dan menjaga layanan. Lihat kebijakan privasi GitHub.

Jika kamu menghubungi dukungan, alamat email dan informasi yang kamu kirim digunakan untuk menangani permintaanmu. Jangan mengirim password atau data pembayaran.

Penyimpanan dan penghapusan

Simpanan lokal bertahan sampai kamu menghapusnya atau menghapus data aplikasi. Penghapusan data aplikasi melalui pengaturan Android menghapus kemajuan dan unduhan lokal; simpan salinan yang diperlukan terlebih dahulu. Tidak ada akun game yang perlu ditutup.
